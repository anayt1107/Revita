# Contributing to Revita

Thank you for your interest in contributing to the Revita project! Your contributions are vital to the success of this project, and we welcome your input. Please follow the guidelines below to ensure a smooth collaboration.

## Code of Conduct

We expect all contributors to adhere to our [Code of Conduct](CODE_OF_CONDUCT.md). This document outlines our expectations for behavior in the community and how to report unacceptable behavior.

## Development Setup

To get started with developing for Revita, follow these instructions:
1. **Clone the repository:**  
   `git clone https://github.com/anayt1107/Revita.git`

2. **Install dependencies:**  
   Navigate to the project folder and run:  
   `npm install`  
   *(or any other package manager or commands specific to the project.)*

3. **Run the project:**  
   Start the development server with:  
   `npm start`
   *(or the equivalent command for your project.)*

## Commit Conventions

We follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification to create clear, concise commit messages. Please use the following format:

```
<type>(<scope>): <description>

[optional body]

[optional footer]
```

### Types of Commits:
- `feat`: A new feature
- `fix`: A bug fix
- `docs`: Documentation only changes
- `style`: Changes that do not affect the meaning of the code (white-space, formatting, etc)
- `refactor`: A code change that neither fixes a bug nor adds a feature
- `test`: Adding missing tests or correcting existing tests

## Pull Request Process

1. **Fork the repository** and create your branch from `main`.
2. **Make your changes.** Be careful to follow the coding conventions established in this repository.
3. **Test your changes** thoroughly.
4. **Commit your changes** using the conventions outlined above.
5. **Push to your branch** and open a pull request on GitHub.
6. **Wait for feedback.** Collaborate with the maintainers to get your PR merged!

Thank you for contributing to Revita! We look forward to your input!
